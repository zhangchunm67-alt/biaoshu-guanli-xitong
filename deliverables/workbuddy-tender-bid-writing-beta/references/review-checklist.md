# 交付前自查清单

输出候选正文前逐项检查；发现问题先修正，修正不了的写入对应章节的核对说明。

| 项目 | 检查内容 |
|---|---|
| 覆盖 | 输出章节与本轮目标章节一一对应；每个必答项和评分点都已在正文响应，或在核对说明写明原因 |
| 废标红线 | 正文没有与废标红线、★号或实质性条款矛盾的表述；做不到或缺证据的已标 `【废标风险】` |
| 依据 | 所用案例与本章要求相关且适用；数字、日期、金额、主体、人员、资质和效果数据都有来源或标记；承诺只来自本项目依据或用户确认 |
| 评分对应 | 段首直接回应评分点并沿用评分项关键词；详略与分值相称；分档评分没有声称达到证据不支持的档位 |
| 材料 | 同类材料选对了记录，没有把多条合并成一条；主体、年度和有效期符合采购要求 |
| 残留 | 历史客户、项目名称、招标编号、旧日期、旧金额和联系人没有作为本项目信息出现（案例说明、同类业绩中如实引用的除外）；没有其他投标人或合作方的名称；没有“XX公司”“××”“此处填写”等旧稿占位符 |
| 独立成文 | 没有连续照抄参考标书或他人文件的原句、整段；表述按本项目的要求、规模和条件重新组织 |
| 暗标 | 有暗标要求时，范围内没有公司名称、品牌、标识、联系方式、人员姓名和可识别客户；没有带标识、水印或署名的图片 |
| 范围 | 不同标包或同名章节没有混用；“详见”只指向本项目目录中实际存在的章节或原表 |
| 标记 | 每个 `【待补】`、`【待确认】` 都写明缺什么、由谁提供或确认；没有删除标记来让正文显得完整 |

自查结果按输出约定写在“自查结果”中。自查通过只表示候选稿内部一致，不等于资格满足、材料齐全或可直接投标。
