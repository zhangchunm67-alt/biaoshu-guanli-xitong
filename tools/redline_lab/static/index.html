先数清楚，再算准确

导入招标文件 → 在原文里逐句标出废标红线 → 一键对照系统识别结果，算出精确率与召回率。标注和原件都只留在本机。

  1. 导入 右上角「＋ 导入招标文件」，支持 .docx / .doc。
  2. 标注 左侧选中原文里的触发条件，点「标为红线」；整段也可直接标。
  3. 计算 点「计算指标」，查看命中、漏报、误报和 P / R / F1。
  4. 归档 导出标注表，或「全部评测」汇总多份文件并下载报告。
